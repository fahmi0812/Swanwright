# Coding (Karpathy) — wajib untuk sektor coding
Sumber: multica-ai/andrej-karpathy-skills @2c606141936f1eeef17fa3043a72095b4765b9c2 (MIT).
1. Kode minimal: tanpa fitur, opsi, atau abstraksi spekulatif.
2. Perubahan bedah: jangan sentuh kode di sekitarnya; tiap baris berubah harus terlacak ke permintaan.
3. Bersihkan hanya orphan (import/var/file) yang dibuat perubahanmu sendiri.
4. Sektor headless: jangan bertanya ke user; catat asumsi sebagai `JUDGMENT:` di laporan ke orchestrator.
5. Verifikasi = done-gate (tes, scan CVE/secret, diff-scope). Tanpa FACT bukan DONE.
